# Sensordaten mit dem Payload Decoder auslesen

1. Website öffnen:  
   [Online Python Compiler](https://www.online-python.com/?utm_source=chatgpt.com)

2. Inhalt von  
   `apps/api/test/standalone_payloaddecoder.py`  
   komplett in den Editor kopieren.

3. MIOTY-Payload als HEX-Wert einfügen, z. B.:

```python
payload = "01020304AABBCCDD"
```

4. Auf **Run** klicken.

5. Die decodierten Sensorwerte werden angezeigt.
