# Sensor einstellen

1. App LinQS auf das Handy laden
2. NFC einschalten
3. In der App "Advanced" drücken.
4. Read drücken und an den Sensor halten.
5. - Falls der Sensor aus auf die Startseite der App und auf "Activate Sensor" um den Sensor anzuschalten.
   - Falls der Sensor an die gewünschten Parameter einstellen und auf Update and Reboot.
   - Falls der Sonsor an aber keine Tabelle für die Parameter dann kurz warten und nochmal probieren.
