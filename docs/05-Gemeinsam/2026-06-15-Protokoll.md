## Besprochene Themen/ Inhalt:

### 1. Positionierung der Antenne / Antenne
- So hoch wie möglich
- momentane positionierung durch T schlecht
- positionierung bei Zapfsäulen gut
- neue Antenne anschließen (vlt. adapter) (Antenne außen montieren)
- Raspy an alter Lorawan antenne anschließen
- Antenne nicht Innen bzw. vor Fenstern anbringen
- so wenig wie möglich Metall drumherum (schwächt Strahlung)
- Betonwand nicht dramatisch außer wenn mit Metallverkleidet
- Gebäude und Glasscheiben schwächen das Signal
- Die Signale werden reflektiert und umgeleitet
- Antenne unterm Dach anbringen

### 2. Pläne für nächstes Jahr
- mehrere Basisstationen
- neues System alle Basisstationen schicken an eine Basisstation (braucht eine neuen Software release) momentan nur eine Basisstation möglich.
- Die Basisstationen sollten mit einer Vpn im gleichen Netz sein.
- Die Raspys können im neun Basistationsystem genutzt/angeschlossen werden.
